## Version v1.1.20 - Android (1276) & iOS (782)
- Date released: 11-11-2026

1. Add new Teams field.

2. Fix answers that depend on Worktype not clearing when the Worktype changes.

3. Add "Awaiting Approval" filter on the Manager History screen.

4. Move AI image autofill processing to the backend.

5. Fix deep linking issues, including when the user is not logged in.


## Version v1.1.17 - Android (1274) & iOS (780)
- Date released: 16-10-2026

1. Improve organization switching speed and reliability.

2. Add Order Trails for organization switch.

3. Switch between SansPaper apps without having to log in again.

4. Fix Auth0 login screen flashing on Android.

5. Improve History and Manager History screens.


## Version v1.1.15 - Android (1272) & iOS (778)
- Date released: 25-09-2026

1. Add scrolling header title for long form names.

2. Multiple bug fixes and improvements for Worktype field, History, Profile and offline submissions.

3. Fix loading screen and edge-to-edge display issues.


## Version v1.1.13 - Android (1271) & iOS (777)
- Date released: 24-08-2026

1. Add offline mode - forms submitted while offline are queued and sent automatically once back online.

2. Photos in offline forms are uploaded once the connection is restored.

3. Open previously loaded forms while offline.

4. Add outbox status banner with manual retry for pending submissions.

5. Fix Drawing field issues.

6. Upgrade app to Expo SDK 56.

- Date released: 09-07-2026

2. Jobs now use job feeds.

3. Fix Hazards and Control Measures values when submitting a form.

4. Fix Duration field, Drawing field and QR scanner for fields when filling up forms.

7. Fix missing fields, form viewing, draft form and label issues.
